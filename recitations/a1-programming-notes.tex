\section{NumPy: arrays, shapes, and the axis argument}\label{sec:numpy}

\subsection{Shape, dtype, and one row per stimulus}\label{sec:shape}

\begin{codebox}
\begin{verbatim}
A = np.array([[1., 2.],
              [3., 6.],
              [5., 4.]])
A.shape      # (3, 2): 3 rows, 2 columns
A.ndim       # 2
A.dtype      # float64
\end{verbatim}
\end{codebox}

\begin{keybox}
\ask{The convention.} A data matrix is \textbf{stimuli by features}: one \emph{row} per
image, one \emph{column} per pixel, unit, or neuron. So \texttt{X[i]} is the vector for
stimulus $i$ and \texttt{X.shape[0]} is how many stimuli there are. The assignment's
matrices are, for example, \texttt{(120, 4096)}: 120 images, 4{,}096 units.
\end{keybox}

\subsection{Arithmetic on arrays: \texttt{*} is not \texttt{@}}

\begin{codebox}
\begin{verbatim}
A * A        # ELEMENTWISE product, same shape as A: [[1, 4], [9, 36], [25, 16]]
A ** 2       # elementwise square, the same numbers; ** is the power operator
A @ A.T      # MATRIX product: (3, 2) @ (2, 3) -> (3, 3), row dotted with row
3 ^ 2        # 1, not 9: ^ is bitwise XOR in Python, never exponentiation
v = np.array([1., 2., 3.])
v.T.shape    # (3,): transposing a 1-D array does nothing
v[:, None].shape                 # (3, 1): this is how you make a column
[1, 2] + [3, 4], [1, 2] * 2      # on LISTS: [1, 2, 3, 4] and [1, 2, 1, 2]
\end{verbatim}
\end{codebox}

\texttt{+}, \texttt{-}, \texttt{*}, \texttt{/} and \texttt{**} act entry by entry on
arrays; \texttt{@} (or \texttt{np.dot}) is the matrix product of the companion handout.
On lists, \texttt{+} concatenates and \texttt{*} repeats. Convert with \texttt{np.array}.

\subsection{Indexing and slicing}

\begin{codebox}
\begin{verbatim}
A[0]         # array([1., 2.])    row 0
A[:, 1]      # array([2., 6., 4.])  column 1
A[:2]        # rows 0 and 1
A[-1]        # array([5., 4.])    last row
A[1, 0]      # 3.0                 row 1, column 0
\end{verbatim}
\end{codebox}

Indices start at 0, so the last valid row of a 120-row matrix is 119. Basic slices such as
\texttt{A[:2]} share memory with \texttt{A}: changing one changes the other. Use
\texttt{.copy()} for an independent array. Boolean and integer-array indexing (\S\ref{sec:broadcast}, \S\ref{sec:ix}) return copies.

\subsection{Reshaping}

\begin{codebox}
\begin{verbatim}
np.arange(6)                 # array([0, 1, 2, 3, 4, 5])
np.arange(6).reshape(2, 3)   # [[0, 1, 2], [3, 4, 5]]: same numbers, read row by row
np.arange(6).reshape(2, -1)  # -1 means "whatever fits": also (2, 3)
imgs.reshape(len(imgs), -1)  # usage pattern: (n, 200, 200) -> (n, 40000)
np.stack([A[0], A[1]])       # two vectors -> one (2, 2) matrix, one per row
\end{verbatim}
\end{codebox}

\subsection{The axis argument}

\begin{keybox}
\ask{Reductions and \texttt{axis}.} For a reduction such as \texttt{mean}, \texttt{sum} or
\texttt{std}, \texttt{axis} names the dimension being combined. By default that dimension
disappears from the result; \texttt{keepdims=True} keeps it with length 1.
\texttt{A.mean(axis=0)} combines the rows and leaves one number per column;
\texttt{A.mean(axis=1)} combines the columns and leaves one number per row.
\end{keybox}

\begin{codebox}
\begin{verbatim}
A.mean(axis=0)                  # array([3., 4.])         shape (2,)
A.mean(axis=1)                  # array([1.5, 4.5, 4.5])  shape (3,)
A.mean(axis=1, keepdims=True)   # array([[1.5], [4.5], [4.5]])  shape (3, 1)
A.sum(), A.max(axis=0), A.std(axis=1)   # same rule for every reduction
np.cumsum([2, 3, 1])            # running total: array([2, 5, 6])
\end{verbatim}
\end{codebox}

\subsection{Broadcasting}\label{sec:broadcast}

When two arrays have different shapes, NumPy stretches any size-1 dimension to match.
Compare shapes \emph{from the right}: each pair must be equal, or one of them must be 1.
A missing leading dimension counts as 1.

\begin{codebox}
\begin{verbatim}
A + np.array([10., 20.])              # (3,2) + (2,)  -> one offset per column
# array([[11., 22.],
#        [13., 26.],
#        [15., 24.]])
A + np.array([[10.], [20.], [30.]])   # (3,2) + (3,1) -> one offset per row
# array([[11., 12.],
#        [23., 26.],
#        [35., 34.]])
A + np.array([10., 20., 30.])         # (3,2) + (3,)  -> expected error:
# ValueError: operands could not be broadcast together with shapes (3,2) (3,)
\end{verbatim}
\end{codebox}

\texttt{axis} selects which entries a reduction combines; \texttt{keepdims} (or
\texttt{v[:, None]}) controls the result's shape so that it broadcasts back against the
matrix the way you intend. The third line fails because \texttt{(3,)} lines up against
the \emph{columns} (2), not the rows. A wrong broadcast can also run without any error
when the sizes happen to match, so check the result's shape and a value or two.

\subsection{Boolean masks}

\begin{codebox}
\begin{verbatim}
labels = np.array(['a', 'b', 'a'])
mask = (labels == 'a')       # array([ True, False,  True])
A[mask]                      # rows 0 and 2, as a new (2, 2) array
mask.sum()                   # 2  (True counts as 1)
mask.mean()                  # 0.667: the FRACTION that is True
np.isin(labels, ['a', 'c'])  # membership test, one boolean per entry
\end{verbatim}
\end{codebox}

Combine masks with \texttt{\&}, \texttt{|}, \texttt{\textasciitilde}, always with
parentheses: \texttt{(labels == 'a') | (labels == 'b')}. Writing \texttt{and} or
\texttt{or} between arrays raises ``truth value of an array is ambiguous''.

\subsection{Sorting, unique values, and the upper triangle}\label{sec:triu}

\begin{codebox}
\begin{verbatim}
v = np.array([0.3, 0.1, 0.7, 0.2])
np.argsort(v)            # array([1, 3, 0, 2]): INDICES, smallest first
np.argsort(v)[::-1]      # largest first
np.unique(labels, return_counts=True)   # (array(['a','b']), array([2, 1]))

iu = np.triu_indices(4, k=1)   # upper triangle of a 4 x 4, no diagonal
iu                       # (array([0,0,0,1,1,2]), array([1,2,3,2,3,3]))
M = np.arange(16).reshape(4, 4)
M[iu]                    # array([1, 2, 3, 6, 7, 11]): 6 = 4*3/2 entries
\end{verbatim}
\end{codebox}

\texttt{argsort} returns positions, not values. \texttt{triu\_indices(N, k=1)} is a
\emph{pair} of index arrays that walk the entries above the diagonal in a fixed order;
\texttt{D[iu]} pulls those $N(N-1)/2$ entries out as a flat vector. If two matrices list
the same stimuli in the same order, the same \texttt{iu} extracts corresponding pairs.

\subsection{Reordering rows and columns together}\label{sec:ix}

\begin{codebox}
\begin{verbatim}
order = np.array([2, 0, 3, 1])   # a permutation of all four indices
M[np.ix_(order, order)]   # rows AND columns in that order: the 4 x 4, rearranged
M[order, order]           # NOT that: M[2,2], M[0,0], M[3,3], M[1,1] -> 4 entries
\end{verbatim}
\end{codebox}

Two index arrays side by side are read as \emph{pairs} of coordinates. \texttt{np.ix\_}
selects every combination of the specified rows and columns, which is what ``sort the
matrix by category'' means. An \texttt{order} shorter than the matrix selects a
sub-matrix.

\subsection{Diagonals, percentiles, tolerances, and missing values}

\begin{codebox}
\begin{verbatim}
np.fill_diagonal(M, 0)          # in place; returns None
np.diag(M)                      # the diagonal as a vector
np.percentile(v, [2, 98])       # two numbers: 2nd and 98th percentile of v
np.allclose(a, b)               # usage pattern: equal within rtol=1e-5, atol=1e-8?
w = np.array([-1., 2., -3.])
np.where(w < 0, 0., w)          # array([0., 2., 0.]): a NEW array, entry by entry

B = np.array([[1., np.nan], [3., 4.], [5., 6.]])
np.isnan(B).sum()               # 1: how many NaNs
np.isnan(B).any(axis=0)         # array([False,  True]): which COLUMNS have any
np.nanmean(B, axis=0)           # array([3., 5.]): mean ignoring NaNs
\end{verbatim}
\end{codebox}

\texttt{np.allclose} answers ``equal within the chosen absolute and relative tolerances'';
its defaults accept differences much larger than floating-point roundoff, so pass
\texttt{atol=} when the scale matters, and check shapes separately (arrays of different
shapes may broadcast and still compare). Ordinary means, correlations and distances
propagate NaNs; the \texttt{nan}-aware functions skip them, but an all-NaN column still
has no mean. Replacing missing observations changes the analysis: use the preprocessing
rule the notebook specifies.

\section{SciPy and scikit-learn: the calls the notebooks use}\label{sec:calls}

\subsection{Distances: \texttt{pdist} and \texttt{squareform}}

\begin{codebox}
\begin{verbatim}
from scipy.spatial.distance import pdist, squareform
d = pdist(A, metric='euclidean')   # CONDENSED: shape (n*(n-1)/2,), one per pair
d                                  # array([4.472, 4.472, 2.828])
D = squareform(d)                  # SQUARE: shape (3, 3), symmetric, zero diagonal
squareform(D)                      # and back to the condensed form
\end{verbatim}
\end{codebox}

\texttt{metric} is any of \texttt{'euclidean'}, \texttt{'cosine'},
\texttt{'correlation'}, and others. When you supply precomputed dissimilarities, MDS
expects the square form and \texttt{linkage} expects the condensed form. \texttt{squareform}
checks that a square input is symmetric with a zero diagonal and raises if not; that is a
useful check, not an obstacle, so find the cause before reaching for
\texttt{checks=False}, which skips the check without repairing anything.

\subsection{The scikit-learn pattern for embeddings}

The embedding methods used here (PCA, MDS, t-SNE) follow one pattern: put the settings in
the constructor, hand the data to \texttt{fit\_transform}, and read anything it learned
from an attribute with a \emph{trailing underscore}.

\begin{codebox}
\begin{verbatim}
from sklearn.decomposition import PCA
pca = PCA(n_components=2)
Y = pca.fit_transform(A)            # A is (3, 2) in  ->  Y is (3, 2) out
pca.explained_variance_ratio_       # array([0.75, 0.25]): variance per component
\end{verbatim}
\end{codebox}

\texttt{Y} holds one row of component scores per row of \texttt{A}. PCA centres each
feature (column) across the rows; it does not centre each row across its features, and it
does not rescale the features. The ratios are sorted, largest first, and sum to 1 when
\texttt{n\_components} equals the number of features.

\subsection{MDS with a precomputed dissimilarity matrix}

Multidimensional scaling takes a dissimilarity matrix and looks for points in the plane
whose pairwise distances match it as well as possible. It starts from a random layout and
moves the points to reduce the mismatch, so different starts can give different maps. The
notebook provides the MDS call in Part 2; this is what its arguments mean.

\begin{codebox}
\begin{verbatim}
from sklearn.manifold import MDS
mds = MDS(n_components=2, metric='precomputed', metric_mds=False,
          n_init=4, max_iter=400, random_state=0)    # usage pattern
Y = mds.fit_transform(D)     # D square (n, n) in  ->  Y (n, 2) out
mds.stress_                  # mismatch between map distances and disparities
\end{verbatim}
\end{codebox}

\begin{itemize}
\item \texttt{metric='precomputed'}: \texttt{D} already holds dissimilarities; do not
      recompute them from \texttt{D} as if it were data.
\item \texttt{metric\_mds=False}: nonmetric MDS, which fits only the \emph{rank order} of
      the dissimilarities. \texttt{True} fits their values.
\item \texttt{random\_state} fixes the random start so two runs agree; \texttt{n\_init}
      runs several starts and keeps the best.
\item \texttt{stress\_} is comparable only between runs on the same input with the same
      stress definition. These argument names need scikit-learn $\geq 1.8$; the Part 2
      setup cell installs it. If the error in \S\ref{sec:errors} appears anyway, restart the kernel and
      rerun the setup cell.
\end{itemize}

\subsection{Correlations}

\begin{codebox}
\begin{verbatim}
from scipy.stats import spearmanr, pointbiserialr
res = spearmanr([1, 2, 3, 4], [1, 3, 2, 4])
res.statistic     # 0.8: the rank correlation rho
res.pvalue        # exists, but see below
pointbiserialr([0, 0, 1, 1], [1., 2., 5., 6.]).statistic   # 0.970
np.corrcoef([1, 2, 3], [1, 2, 4])[0, 1]     # 0.982: Pearson r of the two inputs
\end{verbatim}
\end{codebox}

Both inputs must be flat vectors of the same length. \texttt{np.corrcoef} returns the
$2 \times 2$ matrix of correlations among its inputs (ones on the diagonal), so
\texttt{[0, 1]} picks the entry for input 0 against input 1. To compare two symmetric
RDMs over the same ordered stimuli, correlate their corresponding upper-triangle entries
(\S\ref{sec:triu}). RDM entries share stimuli, so the usual p-value does not establish significance
for an RDM correlation.

\subsection{Fitting a curve: \texttt{curve\_fit}, \texttt{polyfit}, \texttt{polyval}}

Fitting and drawing are two separate steps. Fitting finds the parameter values that make a
model function match the observed $(x, y)$ pairs as closely as possible. Drawing evaluates
the fitted function on a fresh, evenly spaced grid of $x$ values (\texttt{np.linspace}) so
the curve looks smooth; the grid is not the data.

\begin{codebox}
\begin{verbatim}
from scipy.optimize import curve_fit

def line(t, m, c):          # first argument is the data; the rest are parameters
    return m * t + c

t = np.array([0., 1., 2., 3., 4.])
y = np.array([1., 3., 5., 7., 9.])
popt, pcov = curve_fit(line, t, y, p0=[1, 0])
popt                        # array([2., 1.]): fitted m, c in the function's order
line(t, *popt)              # the fitted values; * unpacks popt into m, c
np.linspace(0, 4, 50)       # 50 evenly spaced points, for drawing a smooth curve
\end{verbatim}
\end{codebox}

\begin{itemize}
\item \texttt{p0} is the starting guess. Choose values whose predicted curve has a
      plausible scale over the observed inputs; a poor start can send the fit to a wrong
      solution or no solution.
\item \texttt{maxfev} limits the number of function evaluations for the default solver.
      If fitting fails, read the whole message and inspect the inputs, the model function
      and the starting values before raising it. Report a failure you cannot resolve; by
      itself it does not show that the model is wrong.
\item \texttt{np.polyfit(x, y, deg)} fits a polynomial of degree \texttt{deg} and returns
      its coefficients, highest power first; \texttt{np.polyval(coef, x)} evaluates a
      polynomial with those coefficients at \texttt{x}.
\end{itemize}

$R^2$, when a notebook asks for it, is provided as a function in that notebook. With
$\hat{y}_i$ the model's prediction for observation $i$, it is
$1 - \sum_i (y_i - \hat{y}_i)^2 / \sum_i (y_i - \bar{y})^2$: 1 is a perfect fit, 0 is no
better than predicting the mean, negative is worse than that, and a constant target makes
the denominator zero. To compare models directly, compute $R^2$ on the same observed
response values; averaging or binning the data changes the target and its variance.

\subsection{Hierarchical clustering}

\begin{codebox}
\begin{verbatim}
from scipy.cluster.hierarchy import linkage, fcluster, dendrogram
Z = linkage(pdist(A), method='average')   # takes the CONDENSED form; Z is (n-1, 4)
\end{verbatim}
\end{codebox}

Each row of \texttt{Z} records one merge: the two clusters joined, the height (distance)
at which they joined, and the size of the result. \texttt{method} chooses how the distance
between clusters is defined (\texttt{'single'}: closest pair; \texttt{'average'}: mean
over pairs). \texttt{fcluster(Z, t, criterion)} cuts the tree and returns one integer
label per row: with \texttt{criterion='maxclust'} it forms \emph{at most} \texttt{t}
clusters (tied merge heights can produce fewer), with \texttt{criterion='distance'} it
cuts at height \texttt{t}. \texttt{dendrogram(Z)} draws the tree. If you try both
linkage methods, give the results different names rather than overwriting \texttt{Z}.

\subsection{Silhouette scores}

\begin{codebox}
\begin{verbatim}
from sklearn.metrics import silhouette_samples
sil = silhouette_samples(Y, labels)   # usage pattern: Y (n, d), one label per row
                                      # returns (n,): one score per point
\end{verbatim}
\end{codebox}

For each point, the score compares its mean distance to its own group with its mean
distance to the nearest other group. Near 1: much closer to its own group. Near 0: the
two average distances are similar. Negative: closer to another group than to its own.
It needs at least two groups and fewer groups than points. The function returns one score
per image; the notebook says how to summarise those scores.

\section{Sanity checks on a distance matrix}\label{sec:checks}

Run these every time you have made one, before anything downstream reads it. In a
notebook, only the last bare expression in a cell is displayed, so \texttt{print} each
check:

\begin{codebox}
\begin{verbatim}
print('shape', D.shape)                              # (n, n)?
print('symmetric', np.allclose(D, D.T, atol=1e-8))   # 1e-16 off is roundoff
print('zero diagonal', np.allclose(np.diag(D), 0, atol=1e-8))
print('nonnegative', (D >= 0).all())
print('all finite', np.isfinite(D).all())            # catches nan AND inf
off = D[np.triu_indices(len(D), k=1)]   # the off-diagonal entries, each pair once
print('range', off.min(), off.max())
\end{verbatim}
\end{codebox}

If the diagonal is $10^{-8}$ rather than $0$, inspect the values before changing them:
a formula that reaches zero only up to roundoff is fine to clean with
\texttt{np.fill\_diagonal(D, 0)}, but decide that after establishing the discrepancy is
numerical, not before. If \texttt{np.abs(D - D.T).max()} is $10^{-17}$, nothing is wrong.
Cosine and correlation distances lie in $[0, 2]$: excursions of order $10^{-15}$ are
roundoff; larger ones mean the formula or its inputs need checking; a zero-length or
constant row needs the explicit policy the notebook states.

\section{Plotting matrices and embeddings}

\begin{codebox}
\begin{verbatim}
fig, ax = plt.subplots(2, 3, figsize=(12, 7))   # a 2 x 3 grid; ax is a (2, 3) array
lo, hi = np.percentile(D, [2, 98])
im = ax[0, 1].imshow(D, vmin=lo, vmax=hi)       # a matrix as an image
fig.colorbar(im, ax=ax[0, 1])                   # its colour scale
ax[1, 0].scatter(Y[:, 0], Y[:, 1], s=8)          # a 2-D embedding
ax[0, 0].set_title('...'); ax[0, 0].set_xticks([]); ax[0, 0].set_yticks([])
plt.tight_layout(); plt.show()
\end{verbatim}
\end{codebox}

\texttt{vmin} and \texttt{vmax} set which values map to the two ends of the colour scale;
values outside share the end colours but are not removed from the data. Use the limits the
notebook specifies, label every panel, and show a colour bar, since panels with different
limits cannot be compared by colour alone. To colour a scatter by category, loop over the
categories and call \texttt{ax.scatter} once per group with a \texttt{label=}, then
\texttt{ax.legend()}.

\section{Common errors and what they mean}\label{sec:errors}

\newcommand{\err}[1]{{\small\ttfamily #1}\\}
\begin{itemize}
\item \err{ValueError: operands could not be broadcast together with shapes (120,4096) (120,)}
      A reduction dropped an axis. Decide which axis you meant and what shape the result
      should have; \texttt{keepdims=True} or \texttt{[:, None]} restores it (\S\ref{sec:broadcast}).
\item \err{ValueError: shapes (120,4096) and (120,4096) not aligned}
      Matrix product with inner dimensions that do not match. Work out the intended
      operation and its output shape before transposing anything: a \texttt{.T} on the
      wrong operand gives a valid but wrong matrix.
\item \err{IndexError: index 120 is out of bounds for axis 0 with size 120}
      Indices start at 0; the last row is 119.
\item \err{ValueError: The truth value of an array with more than one element is ambiguous}
      \texttt{and}/\texttt{or} between arrays, or \texttt{if array:}. Use \texttt{\&}/\texttt{|}
      with parentheses for masks; use \texttt{.any()} or \texttt{.all()} for a single yes/no.
\item \err{ValueError: Distance matrix 'X' must be symmetric}
      \texttt{squareform} received a square matrix that is not symmetric. Find the
      asymmetry (\texttt{np.abs(D - D.T).max()}) and its cause before continuing.
\item \err{ValueError: The condensed distance matrix must contain only finite values}
      There is a \texttt{nan} or \texttt{inf} in the distances. Locate it
      (\texttt{np.argwhere(\textasciitilde np.isfinite(D))}) and trace it to its input.
\item \err{TypeError: MDS.\_\_init\_\_() got an unexpected keyword argument 'metric\_mds'}
      scikit-learn older than 1.8. Restart the kernel and re-run the setup cell.
\item \err{RuntimeError: Optimal parameters not found}
      \texttt{curve\_fit} did not converge. Check the model, the inputs and \texttt{p0};
      then raise \texttt{maxfev}.
\item \err{TypeError: 'numpy.float64' object is not callable}
      A name that used to be a function is now a number, usually \texttt{r2 = r2(...)}
      or a variable named \texttt{sum}. Rename and re-run the definition.
\item \err{NotImplementedError: 1b: write your code here, then delete this line.}
      The guard line at the bottom of a TODO cell. Delete it once your code is in.
\item \textbf{Unexpected \texttt{nan} results}, with no error at all.
      A \texttt{nan} in the input propagated, or a division by zero occurred. Check which
      axis the computation runs along: a row-wise correlation needs variation within each
      row; standardising units across images needs variation within each column.
\end{itemize}
