Image: course Assignment 1 stimulus bundle, image 28 (stim-0354). All displayed channel values are decoded from the original 224 × 224 image; no resizing or grayscale conversion is used for the values. Channel previews retain only the named color component. Dividing by 255 rescales the encoded values to [0, 1]; it does not linearize light intensity.
