Slide 2

Last lecture: one neuron that learns

  • Perceptron: threshold gg, update only on mistakes
  • Delta rule: no gg, squared error 12(y−y^)2\tfrac12(y-\hat y)^2
  • Logistic: sigmoid gg, cross-entropy loss
  • The model neuron: a weighted sum z=𝐰⊤𝐱+bz = \textcolor{#B5396B}{\mathbf{w}}^\top\textcolor{#3E6D8E}{\mathbf{x}} + \textcolor{#3F7A6B}{b}, then a nonlinearity a=g(z)a = \textcolor{#7A4FA3}{g}(z). Its weights set one decision boundary
  • Learning the weights: compare the output y^=a\hat y = a with the target yy, the right answer. Measure the loss and step against its gradient
  • Perceptron, delta rule, logistic regression: change each weight by η\eta × error × input. Only how the error is computed differs

Slide 3

Learning the weights: start anywhere, walk downhill

  • Each pair (w1,w2)(w_1, w_2) has a loss, here the squared error 12(y−y^)2\tfrac12(y-\hat y)^2 averaged over a small training set; contours join equal losses
  • Start at small random weights 𝐰(0)\textcolor{#B5396B}{\mathbf{w}}^{(0)}. The gradient ∇ℓ=(∂ℓ/∂w1, ∂ℓ/∂w2)\nabla\ell = (\partial\ell/\partial w_1,\ \partial\ell/\partial w_2) points uphill, toward higher loss
  • Each step is a weight update against the gradient; the learning rate η\eta sets its size

𝐰(t+1)=𝐰(t)−η ∇ℓ\textcolor{#B5396B}{\mathbf{w}}^{(t+1)} = \textcolor{#B5396B}{\mathbf{w}}^{(t)} - \eta\,\nabla\ell

  • For one neuron the loss is convex, a bowl with a single minimum. From any start, small enough steps reach the bottom

Slide 4

You never see the whole landscape

  • The contour map was drawn by computing ℓ\ell for every pair (w1,w2)(w_1, w_2) on a grid: easy with only 2 weights
  • With 100 weights and only 10 values tried per weight, the grid has 1010010^{100} points. Real networks have millions of weights: the map can never be drawn
  • Gradient descent never needs the map. At the current weights it computes the gradient: for each weight, which way to move to lower ℓ\ell, and how strongly
  • Why that is cheap: the gradient is a formula, worked out once with calculus (next slides). Evaluating it takes one pass backward through the network, about the cost of the forward pass that computes ℓ\ell. Its cost grows in proportion to the number of weights, not exponentially as the grid does
  • Each small step lowers the loss. A step computed from one example, or from a small batch of examples (minibatches, later today), lowers it on average

Slide 5

The chain rule, one link at a time

  • The weights change the loss only through a chain: 𝐰  →  z=𝐰⊤𝐱  →  y^=g(z)  →  ℓ\textcolor{#B5396B}{\mathbf{w}} \;\to\; z = \textcolor{#B5396B}{\mathbf{w}}^\top \textcolor{#3E6D8E}{\mathbf{x}} \;\to\; \hat y = \textcolor{#7A4FA3}{g}(z) \;\to\; \ell
  • Chain rule of calculus: if ℓ=f(u)\ell = f(u) and u=h(w)u = h(w), then dℓdw=dℓdu dudw\dfrac{d\ell}{dw} = \dfrac{d\ell}{du}\,\dfrac{du}{dw}. A longer chain multiplies one slope per link. This gives the gradient of the loss with respect to each weight

∂ℓ∂𝐰=∂ℓ∂y^  ∂y^∂z  ∂z∂𝐰\frac{\partial\ell}{\partial \textcolor{#B5396B}{\mathbf{w}}}=\frac{\partial\ell}{\partial\hat y}\;\frac{\partial\hat y}{\partial z}\;\frac{\partial z}{\partial \textcolor{#B5396B}{\mathbf{w}}}

  • Link y^→ℓ\hat y \to \ell:   ∂ℓ/∂y^\;\partial\ell/\partial\hat y, set by the loss
  • Link z→y^z \to \hat y:   ∂y^/∂z=g′(z)\;\partial\hat y/\partial z = \textcolor{#7A4FA3}{g}'(z), the slope of the output function
  • Link 𝐰→z\textcolor{#B5396B}{\mathbf{w}} \to z:   ∂z/∂𝐰=𝐱\;\partial z/\partial \textcolor{#B5396B}{\mathbf{w}} = \textcolor{#3E6D8E}{\mathbf{x}}, because z=w1x1+w2x2+bz = w_1x_1 + w_2x_2 + b
  • Multiply the three slopes and you have the gradient

Slide 6

The three links, worked out: delta rule

Output y^=z\hat y = z (no nonlinearity), loss ℓ=12(y−y^)2\ell = \tfrac12(y-\hat y)^2

∂ℓ∂y^=12⋅2 (y−y^)⋅(−1)=−(y−y^)\frac{\partial\ell}{\partial\hat y} = \tfrac12\cdot 2\,(y-\hat y)\cdot(-1) = -(y-\hat y)

∂y^∂z=1∂z∂𝐰=𝐱\frac{\partial\hat y}{\partial z} = 1 \qquad\qquad \frac{\partial z}{\partial \textcolor{#B5396B}{\mathbf{w}}} = \textcolor{#3E6D8E}{\mathbf{x}}

∂ℓ∂𝐰=−(y−y^)⋅1⋅𝐱=−(y−y^) 𝐱\frac{\partial\ell}{\partial \textcolor{#B5396B}{\mathbf{w}}} = -(y-\hat y)\cdot 1\cdot \textcolor{#3E6D8E}{\mathbf{x}} = -(y-\hat y)\,\textcolor{#3E6D8E}{\mathbf{x}}

  • Step against it: Δ𝐰=η (y−y^) 𝐱\Delta \textcolor{#B5396B}{\mathbf{w}} = \eta\,(y-\hat y)\,\textcolor{#3E6D8E}{\mathbf{x}}, the delta rule

Slide 7

The three links, worked out: logistic regression

Output y^=σ(z)=11+e−z\hat y = \sigma(z) = \dfrac{1}{1+e^{-z}}, loss ℓ=−[ ylog⁡y^+(1−y)log⁡(1−y^) ]\ell = -\big[\,y\log\hat y + (1-y)\log(1-\hat y)\,\big]

∂ℓ∂y^=−yy^+1−y1−y^=−y(1−y^)+(1−y) y^y^(1−y^)=−y−y^y^(1−y^)\frac{\partial\ell}{\partial\hat y} = -\frac{y}{\hat y}+\frac{1-y}{1-\hat y} = \frac{-y(1-\hat y)+(1-y)\,\hat y}{\hat y(1-\hat y)} = -\frac{y-\hat y}{\hat y(1-\hat y)}

∂y^∂z=σ(z)(1−σ(z))=y^(1−y^)∂z∂𝐰=𝐱\frac{\partial\hat y}{\partial z} = \sigma(z)\big(1-\sigma(z)\big) = \hat y(1-\hat y) \qquad\qquad \frac{\partial z}{\partial \textcolor{#B5396B}{\mathbf{w}}} = \textcolor{#3E6D8E}{\mathbf{x}}

∂ℓ∂𝐰=−y−y^y^(1−y^)⋅y^(1−y^)⋅𝐱=−(y−y^) 𝐱\frac{\partial\ell}{\partial \textcolor{#B5396B}{\mathbf{w}}} = -\frac{y-\hat y}{\hat y(1-\hat y)}\cdot\hat y(1-\hat y)\cdot \textcolor{#3E6D8E}{\mathbf{x}} = -(y-\hat y)\,\textcolor{#3E6D8E}{\mathbf{x}}

  • The sigmoid's slope cancels the loss's denominator: the same form as the delta rule

Slide 8

The perceptron: no slope to follow

  • Output y^=sign(z)\hat y = \mathrm{sign}(z): flat, then a jump. Its slope is 0 almost everywhere: the chain rule gives nothing
  • Instead, its loss uses zz directly, with labels y=±1y = \pm 1: the perceptron criterion ℓ=max⁡(0, −y z)\ell = \max(0,\,-y\,z). It is 0 on the correct side of the boundary and grows with how far an example is on the wrong side
  • On a mistake its gradient is −y 𝐱-y\,\textcolor{#3E6D8E}{\mathbf{x}}, otherwise 0. Stepping against it gives Rosenblatt's rule: on each mistake, Δ𝐰=η y 𝐱\Delta \textcolor{#B5396B}{\mathbf{w}} = \eta\,y\,\textcolor{#3E6D8E}{\mathbf{x}}
  • Three rules, one recipe: pick an output and a loss, then step against the gradient

XOR is built from simpler rules

  • XOR is OR, and NOT AND:   x1 XOR x2=(x1∨x2)∧¬(x1∧x2)\;x_1 \,\text{XOR}\, x_2 = (x_1 \lor x_2) \land \lnot(x_1 \land x_2)
  • Each simpler rule is one perceptron, one line (below). Stack them: OR and AND in a first layer, a neuron combining their outputs in a second. What one neuron cannot compute, a stack of neurons can

Slide 12

Past the XOR wall: stack neurons into layers

  • One neuron draws one line: at best 3 of the 4 XOR points
  • Two hidden units draw the OR line and the AND line; the output fires between them: all 4 right
  • A multilayer perceptron (MLP) stacks layers: each layer's outputs are the next layer's inputs, and every unit takes a weighted sum, then a nonlinearity. Stacked neurons draw boundaries that one line cannot

Slide 15

Backpropagation: a long and disputed history

  • 1958: Rosenblatt's perceptron learns its weights from examples, but only one layer of them
  • 1969: Minsky & Papert show that a perceptron cannot compute XOR. No widely known method trains hidden layers, and interest in neural networks fades
  • 1970–1974: Linnainmaa, studying rounding errors in computer programs, computes all the derivatives of a long calculation in one backward sweep. Werbos: general models in 1974, neural networks in 1982
  • 1986: Rumelhart, Hinton & Williams show that hidden units trained this way learn useful internal representations. Their Nature paper made backprop the standard method
  • Who deserves the credit is still argued. Hinton's 2024 Nobel Prize in Physics, shared with Hopfield, cited a different kind of network, the Boltzmann machine, not backprop. His 2018 Turing Award, shared with Bengio and LeCun, was for deep learning as a whole
Rosenblatt Psychol Rev 1958 · Rumelhart, Hinton & Williams Nature 1986 · NobelPrize.org Physics 2024 · ACM Turing Award 2018

Slide 17

How should each weight change?

  • Compare the output with its target: the error is y^−y=0.54−1=−0.46\hat y - y = 0.54 - 1 = -0.46. Negative, so raise y^\hat y
  • The goal: change the weights a little, so that next time the output lands closer to its target
  • For each weight, ask: if it grew slightly, would the loss ℓ\ell of this example go up or down, and how fast? That slope is the gradient. Step against it: w←w−η ∂ℓ/∂ww \leftarrow w - \eta\,\partial\ell/\partial w
  • A weight into the output gets the output error directly. A hidden unit's error is the output error sent back along its connection, times that connection's weight (0 if the unit was off)
  • The chain rule: when ww acts on ℓ\ell through zz and then aa,   ∂ℓ∂w=∂ℓ∂a ∂a∂z ∂z∂w\;\dfrac{\partial\ell}{\partial w}=\dfrac{\partial\ell}{\partial a}\,\dfrac{\partial a}{\partial z}\,\dfrac{\partial z}{\partial w}, the product of the slopes along the way. Next slide: on this network
  • Activity flows forward to the output. Error flows backward to every weight

Slide 18

The chain rule on this network

  • A weight changes the loss only through what it feeds. Hidden weight w11[1]\textcolor{#B5396B}{w}^{[1]}_{11} (from x1x_1 to hidden unit 1):   w11[1]→z1[1]→a1[1]→z[2]→ℓ\;\textcolor{#B5396B}{w}^{[1]}_{11}\to z^{[1]}_1\to a^{[1]}_1\to z^{[2]}\to\ell
  • Output weight, one link: ∂ℓ∂w1[2]=∂ℓ∂z[2] ∂z[2]∂w1[2]=(y^−y) a1[1]\dfrac{\partial\ell}{\partial \textcolor{#B5396B}{w}^{[2]}_1}=\dfrac{\partial\ell}{\partial z^{[2]}}\,\dfrac{\partial z^{[2]}}{\partial \textcolor{#B5396B}{w}^{[2]}_1}=(\hat y-y)\,a^{[1]}_1
  • Hidden weight, multiply the slopes along the whole chain:

∂ℓ∂w11[1]=∂ℓ∂z[2]⏟y^−y  ∂z[2]∂a1[1]⏟w1[2]  ∂a1[1]∂z1[1]⏟g′(z1[1])  ∂z1[1]∂w11[1]⏟x1\frac{\partial\ell}{\partial \textcolor{#B5396B}{w}^{[1]}_{11}}=\underbrace{\frac{\partial\ell}{\partial z^{[2]}}}_{\textstyle \hat y-y}\;\underbrace{\frac{\partial z^{[2]}}{\partial a^{[1]}_1}}_{\textstyle \textcolor{#B5396B}{w}^{[2]}_1}\;\underbrace{\frac{\partial a^{[1]}_1}{\partial z^{[1]}_1}}_{\textstyle g'(z^{[1]}_1)}\;\underbrace{\frac{\partial z^{[1]}_1}{\partial \textcolor{#B5396B}{w}^{[1]}_{11}}}_{\textstyle x_1}

  • With the worked example's numbers (next slides):   (−0.46)×0.70×1×1=−0.32\;(-0.46)\times 0.70\times 1\times 1 = -0.32
  • Step 2 computes the first factor, step 3 the middle two, step 4 multiplies by the input

Step 1: the forward pass

  • Run the input through, keeping every weighted sum zz and output aa
  • Hidden (ReLU): a1[1]=0.50a^{[1]}_1 = 0.50, a2[1]=0.30a^{[1]}_2 = 0.30. Output (sigmoid): z[2]=0.17z^{[2]} = 0.17, y^=σ(0.17)=0.54\hat y = \sigma(0.17) = 0.54

Slide 21

Step 2: the error at the output

  • Sigmoid + cross-entropy: error = prediction − target: δ[2]=∂ℓ/∂z[2]=y^−y=−0.46\textcolor{#3F7A6B}{\delta^{[2]}} = \partial\ell/\partial z^{[2]} = \hat y - y = -0.46

Slide 22

Step 3: send the error backward

  • A hidden unit's error = output error × the linking weight × its ReLU slope g′g' (1 if on, 0 if off)
  • δ1[1]=δ[2] w1[2] g′(z1[1])=−0.46×0.70×1=−0.32\textcolor{#3F7A6B}{\delta^{[1]}_1} = \textcolor{#3F7A6B}{\delta^{[2]}}\,\textcolor{#B5396B}{w^{[2]}_1}\,g'(z^{[1]}_1) = -0.46\times0.70\times1 = -0.32; δ2[1]=−0.46×(−0.60)×1≈0.27\textcolor{#3F7A6B}{\delta^{[1]}_2} = -0.46\times(-0.60)\times1 \approx 0.27
  • Each hidden unit gets its own error, even its own sign: a1[1]a^{[1]}_1 should have been higher, a2[1]a^{[1]}_2 lower

Slide 23

Step 4: every gradient is error × activity

  • gradient = error × activity: ∂ℓ/∂w1[2]=−0.46×0.50=−0.23\partial\ell/\partial \textcolor{#B5396B}{w^{[2]}_1} = \textcolor{#3F7A6B}{-0.46}\times\textcolor{#3E6D8E}{0.50} = -0.23
  • Weights from x2x_2 get 0, since x2=0x_2 = 0. Each bias gets its unit's error: −0.32-0.32, 0.270.27, −0.46-0.46
  • One step with η=1\eta = 1 on all weights and biases: y^\hat y rises from 0.54 to 0.82

Slide 24

Why it works: the chain rule, run backward

  • The loss depends on the weight w11[1]w^{[1]}_{11} (from x1x_1 to a1[1]a^{[1]}_1) through a chain: w11[1]→z1[1]→a1[1]→z[2]→ℓw^{[1]}_{11}\to z^{[1]}_1\to a^{[1]}_1\to z^{[2]}\to\ell. The chain rule multiplies the local slopes along it, as steps 2 to 4 did
  • Backprop is the chain rule of multivariable calculus, applied layer by layer. You will not be asked to derive it. If you have taken multivariable calculus, the derivation is in the backpropagation notes

Slide 25

With hidden layers, the landscape is no longer a bowl

  • Once a network has hidden layers, the loss is not convex: it has many valleys, local minima
  • Backpropagation gives the gradient; gradient descent goes down from wherever it starts. Different starts can end in different minima, and nothing guarantees the best one
  • In practice, large networks usually reach a minimum that works well. That is an observation, not a guarantee

Slide 28

Many classes: softmax and cross-entropy

p^c=ezc∑jezj,ℓ=−log⁡p^true class\textcolor{#3E6D8E}{\hat p}_c = \frac{e^{z_c}}{\sum_j e^{z_j}}, \qquad \ell = -\log \textcolor{#3E6D8E}{\hat p}_{\text{true class}}

  • One weighted sum per class cc, the logits zcz_c. The softmax turns them into probabilities; the loss: −log of the true class's probability
  • Example: logits (2,1,0)(2, 1, 0) give 𝐩^=(0.67,0.24,0.09)\textcolor{#3E6D8E}{\hat{\mathbf p}} = (0.67, 0.24, 0.09). True class 1: ℓ=0.41\ell = 0.41. True class 3: ℓ=2.41\ell = 2.41
  • Right and confident, ℓ→0\ell \to 0; wrong and confident, ℓ\ell grows without bound

One training step, and one epoch

  • One step: a batch (a set of examples processed together) forward, one number ℒ (their average loss), its gradient for every weight, then every weight moves a little
  • One epoch: every example in the training set once. Training repeats epochs while ℒ falls

Slide 31

The training loop

model = nn.Linear(D, K) # D inputs, one logit for each of K classes loss_fn = nn.CrossEntropyLoss() # softmax + cross-entropy, averaged opt = torch.optim.SGD(model.parameters(), lr=0.1) # SGD: a plain gradient step for epoch in range(num_epochs): # one epoch = one pass over the training set opt.zero_grad() # 1. clear the old gradients logits = model(X_train) # 2. forward: logits for every image loss = loss_fn(logits, y_train) # 3. the average cross-entropy loss.backward() # 4. gradient of the loss for every weight opt.step() # 5. update: w <- w - lr * gradient with torch.no_grad(): # evaluate on held-out images acc = (model(X_test).argmax(1) == y_test).float().mean()
  • This model is a linear readout. To train a hidden layer, change only the model line
  • backward() computes the gradients. opt, the optimizer, turns them into weight changes in step()
  • This is the delta rule's loop, written for a whole layer: forward, loss, gradient, step, repeat

Slide 32

Autograd: you never write the backward pass

  • PyTorch's automatic differentiation (autograd) records the forward pass as a computational graph: the operations that ran, and the values each one used
  • loss.backward() sweeps the graph in reverse: output error, hidden errors, then each parameter's gradient, stored in its .grad. opt.step() applies the update
Baydin, Pearlmutter, Radul & Siskind JMLR 2018

Slide 33

Check a gradient by nudging

loss = loss_fn(x, y) # forward pass: 0.6118 loss.backward() # W1.grad[0, 0] = -0.320 with torch.no_grad(): W1[0, 0] += 0.001 # nudge one weight by 0.001 new_loss = loss_fn(x, y) # forward pass again: 0.6114 print((new_loss - loss) / 0.001) # -0.320: the same slope
  • Nudge one weight, rerun the forward pass, divide the change in the loss by the nudge: step 4's −0.32-0.32
  • A nudge costs one forward pass per weight; backprop gets every gradient in one backward sweep. Nudges check a backward pass; they do not train
  • On paper: change one weight a little, redo step 1, compare the change in the loss with step 4

Slide 34

Train only part of a network

model = nn.Sequential(nn.Linear(D, 64), nn.ReLU(), nn.Linear(64, K)) model.load_state_dict(torch.load("trained.pt")) # weights trained earlier for p in model[0].parameters(): # the hidden layer p.requires_grad = False # no gradients: these weights stay fixed opt = torch.optim.Adam(model[2].parameters(), lr=1e-3) # Adam: an optimizer, defined later
  • To freeze a trained layer, turn off its gradients and give the optimizer only the weights that should learn
  • Readout only: cheap. It shows what a trained readout can find in the hidden layer's fixed responses
  • Every weight: backpropagation also changes the hidden layer, so its responses to the images change too
  • Same data, same loss: only the set of weights allowed to move differs

Slide 36

Minibatches: a gradient from a few examples at a time

  • Full batch: the gradient over all NN training examples at every step. Exact, but slow for large NN
  • Minibatch: shuffle the data, then take one step per batch of BB examples (often 32 to 256). One step is also called an iteration or update; an epoch holds many
  • Each minibatch gradient is a noisy estimate of the full one. It is much cheaper, and the noise can help the weights escape shallow dips in the loss
  • With B=1B = 1 this is the original stochastic gradient descent (PyTorch's optim.SGD: this step at any batch size)
Robbins & Monro Ann Math Stat 1951

Slide 37

Shrink the step: learning-rate schedules

  • Noisy minibatch gradients: a constant step keeps bouncing; too large overshoots, too small crawls
  • A schedule lowers η\eta during training: large steps early, small late. Top: step sizes; bottom: losses (dashed: the lowest possible)
  • Step decay halves η\eta at fixed intervals (every 200 steps here). Cosine lowers it smoothly to near 0. 1/(1+t/τ)1/(1+t/\tau) shrinks it a little at every step tt; τ\tau sets how soon the shrinking starts
  • In the last-200-steps inset, the shrinking schedules fluctuate less

Slide 38

Adam: the most popular optimizer

𝐦←β1𝐦+(1−β1) ∇L,𝐯←β2𝐯+(1−β2) (∇L)2,θ←θ−η 𝐦𝐯+ϵ\mathbf{m}\leftarrow\beta_1\mathbf{m}+(1-\beta_1)\,\nabla\mathcal{L},\qquad \mathbf{v}\leftarrow\beta_2\mathbf{v}+(1-\beta_2)\,(\nabla\mathcal{L})^2,\qquad \boldsymbol{\theta}\leftarrow\boldsymbol{\theta}-\eta\,\frac{\mathbf{m}}{\sqrt{\mathbf{v}}+\epsilon}

θ: all weights and biases · operations are per weight · Adam's first-step correction omitted

  • Momentum (𝐦\mathbf{m}): a running average of recent gradients. The noisy parts of successive minibatch gradients cancel; a consistent direction adds up
  • A step size for each weight (𝐯\mathbf{v}): each weight's step is divided by the typical size of its own gradient. Weights with small gradients still move, and large gradients are scaled down
  • β1\beta_1 and β2\beta_2 set how much of each running average is kept at every step. The defaults, β1=0.9\beta_1=0.9 and β2=0.999\beta_2=0.999, work on most problems. ϵ\epsilon, a tiny number, prevents division by zero
  • Usually fewer steps to a low loss than plain gradient descent, but it still needs a learning rate
Kingma & Ba ICLR 2015 · Loshchilov & Hutter ICLR 2019 · Wilson, Roelofs, Stern, Srebro & Recht NeurIPS 2017

Slide 39

The learning rate, measured

  • Four runs of one network (64 ReLU hidden units) on handwritten digits, differing only in η\eta; "test" = accuracy on held-out images
  • Too large a step can switch a ReLU unit off on every input: a dead unit
  • Too small: the loss barely moves. Too large: it sticks at chance (−log 1/10 ≈ 2.3); the units died
  • The range that works spans orders of magnitude, so sweep η\eta on a log scale, and sweep it first

Slide 40

Recap

  • Hidden layers: one neuron draws one line. Two ReLU hidden units re-represent the XOR inputs so that one line separates the classes
  • Backpropagation: forward pass, error at the output (y^−y\hat y - y), error sent backward through the weights, and every gradient is error × activity. Autograd runs these steps for you
  • The training loop: a softmax readout for many classes, then forward, loss, backward(), step(), repeated over epochs. Freezing a trained layer trains only the readout
  • Step sizes: minibatches, a learning rate that shrinks, and Adam. Sweep η\eta on a log scale first

Slide 42

Weight transport: must feedback copy the weights?

  • Backprop sends the error back through the forward weights 𝐖⊤\textcolor{#B5396B}{\mathbf{W}}^{\top}, so feedback synapses would have to copy them (weight transport)
  • With fixed random feedback weights 𝐁\mathbf{B} instead, the forward weights adapt until the hidden units' updates point within 90°90° of backprop's (panel b)
  • On MNIST (handwritten digits), 2.1% test error vs 2.4% for backprop

Error signals in dendrites, one per neuron

  • Mice turned a grating with a brain–computer interface (BCI): a few layer-5 neurons (P+) rotated it toward the target, others (P−) away
  • Their apical dendrites carried error-related signals of opposite sign, matching each group's effect: each neuron its own error. Silencing them disrupted learning (caveat: a BCI task)

Slide 44

Why do codes drift? Noisy steps never stop

  • Drift: a neuron's tuning changes while behavior holds. In mouse visual cortex it speeds up for the images being shown
  • Our digit network, loss settled, learning on from noisy feedback: small batches at a constant η\eta keep moving its tuning
  • A shrinking η\eta or full-batch steps: tuning settles. Accuracy stays near 98% in all three
  • Noisy steps that never shrink move the code, not the performance

A weight update that keeps synapses brain-like

  • Left: EG's weights are log-normal, as in cortex: their logs follow a bell curve
