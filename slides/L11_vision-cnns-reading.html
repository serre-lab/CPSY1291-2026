Slide 10

Regularization 2: dropout

  • Dropout: at each training step, switch off a random half of the hidden units; all are on at test time
  • Often with the weight penalty, sometimes L1 (absolute values): each cuts the freedom to fit noise
Srivastava et al. JMLR 2014

Slide 19

Dense versus convolutional: where the weights go

  • The perceptron wires every pixel to every unit. The convolutional layer wires each unit to a patch, and every unit shares the same weights: a feature detector copied across the image

Slide 20

Count the weights: a dense layer on an image

  • Flatten a 224 × 224 colour image: one dense unit needs 224 · 224 · 3 = 150,528 weights, and it ignores which pixels are neighbours
  • AlexNet's first layer instead learns 96 small filters of 11 × 11 × 3 and reuses each one at every position: 34,848 weights, about 400 times fewer than 96 dense units
  • An object can sit anywhere in the image, so the detector is needed at every position: local filters, the same everywhere
Krizhevsky, Sutskever & Hinton NeurIPS 2012

Slide 23

Convolution: one filter, slid over the image

Computed on the tiger photograph of the first lecture

  • A filter (or kernel): a small grid of weights, the template of the previous slide. At each position, multiply by the pixels under it and sum; a ReLU sets negatives to 0
  • The result is a feature map: how well each part of the image matches the filter
  • Same weights everywhere: shift the image, and the map shifts with it (equivariance)

Slide 26

Stride and padding set the size of a map

  • One filter at every position gives a map as large as the image; two settings change that. Stride ss: how far the filter moves between positions; stride 2 halves the map's height and width
  • Padding pp: rows and columns of zeros around the input, so the filter can also sit on the border
  • Output size for a k×kk \times k filter: Hl=⌊(Hl−1+2p−k)/s⌋+1H_l = \lfloor (H_{l-1} + 2p - k)/s \rfloor + 1. ResNet-50's first layer: 224, k=7k = 7, s=2s = 2, p=3p = 3, gives 112

Slide 27

Pooling: from a map to fewer numbers

  • A map says where a feature is, to the pixel; recognition needs whether, roughly where. Max-pooling keeps the largest value in each window: the same answer when the feature shifts a little, tolerance to position (the complex cell, next)
  • Global average pooling averages each map over all positions: one number per channel; together they form the image's feature vector, the readout's input
Lin, Chen & Yan ICLR 2014

Slide 54

Cortical columns: every orientation, at every position

  • Hubel and Wiesel's ice-cube model: a small block of V1 holds every orientation for both eyes; the block is repeated across the whole visual field
  • So the same oriented template exists at every position, each copy a separate set of cells: replication
  • Cortex does with cells what the convolution did with one filter: the same template at every position
Hubel & Wiesel Proc R Soc B 1977 · Kandel, Schwartz & Jessell, Principles of Neural Science

Slide 56

Fukushima's Neocognitron (1980)

  • S-cells: simple cells, one template per plane, at every position. C-cells: pool nearby S-cells of one plane
  • Repeat S then C; the top responds to a whole digit wherever it sits. Trained without labels, layer by layer
Fukushima Biol Cybern 1980 · Hubel & Wiesel J Physiol 1962

The test on behaviour: rapid animal categorization

  • Serre, Oliva & Poggio (2007): the task of the opening slide, 20 ms images, a mask after 80 ms to cut off feedback
  • The model's accuracy, as d′d', matched people's at every viewing distance, and it was wrong on the same images more often than chance

Slide 60

Recap

  • Generalize better: a penalty on the weights (weight decay, ridge), dropout, more or altered data, with λ chosen on validation data
  • Brain: center–surround, simple cells wired from rows of LGN cells, complex cells that pool them; receptive fields mapped by hand or by reverse correlation
  • History: Neocognitron and HMAX repeat S and C up to IT under physiological constraints and explain rapid categorization. Next lecture: what these networks learn, and what happened when they scaled
  • Network: convolution (one filter, shared), stride and pooling, global average pooling to a feature vector
